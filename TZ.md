## Техническое задание

### 1. Общее описание

Персональный сайт-портфолио разработчика. One-page приложение с плавной навигацией между секциями. Тёмная тема по умолчанию с переключателем на светлую.

### 2. Стек технологий

- **HTML5** — семантическая разметка
- **CSS3** — кастомные свойства (CSS variables), Flexbox/Grid, анимации, медиа-запросы
- **Vanilla JavaScript** — интерактивность без фреймворков
- **Google Fonts** — шрифт Inter (чистый, современный)

### 3. Структура страниц (One-page)

#### 3.1. Header (фиксированный)
- Логотип / Имя (слева)
- Навигация: Обо мне | Навыки | Проекты | Опыт | Контакты (справа)
- Кнопка переключения темы (dark/light) (справа)
- Гамбургер-меню на мобильных

#### 3.2. Hero секция
- Крупный заголовок: "Привет, я [Имя] — Разработчик"
- Подзаголовок: краткое описание (1-2 предложения)
- CTA-кнопки: "Мои проекты" / "Связаться"
- Фоновая анимация (частицы / градиент)

#### 3.3. Обо мне
- Фотография-аватар (плейсхолдер)
- Текстовое описание
- Ссылки: резюме (PDF), соцсети

#### 3.4. Навыки
- Категории: Языки, Фреймворки, Инструменты, Прочее
- Прогресс-бары / теги с уровнем
- Анимация при появлении в viewport

#### 3.5. Проекты
- Карточки проектов (сетка 2-3 колонки)
- Фильтрация по категориям (Все | Frontend | Backend | Fullstack)
- Каждая карточка: скриншот, название, краткое описание, теги, ссылки (GitHub / Live)
- Hover-эффект с оверлеем

#### 3.6. Опыт (Timeline)
- Вертикальная timeline с точками
- Каждый пункт: год, компания, должность, описание
- Анимация появления при скролле

#### 3.7. Контакты
- Форма: Имя, Email, Сообщение, Кнопка отправки
- Ссылки на соцсети (иконки)
- Email и локация

#### 3.8. Footer
- Копирайт
- Ссылки на соцсети
- Кнопка "Наверх"

### 4. Дизайн

#### Цветовая схема
- Dark theme (по умолчанию):
  - Background: #0a0a0a
  - Surface: #111111
  - Card: #1a1a1a
  - Text primary: #e0e0e0
  - Text secondary: #888888
  - Accent: #64ffda (мятный, вдохновлён Brittany Chiang)
  - Accent hover: #45e0be

- Light theme:
  - Background: #ffffff
  - Surface: #f5f5f5
  - Card: #eeeeee
  - Text primary: #1a1a1a
  - Text secondary: #666666
  - Accent: #0a9e80
  - Accent hover: #088568

#### Типографика
- Heading 1: 3.5rem / bold / Inter
- Heading 2: 2.5rem / bold / Inter
- Heading 3: 1.5rem / semibold / Inter
- Body: 1rem / regular / Inter
- Small: 0.875rem / regular / Inter

#### Отступы
- Секции: padding 100px 0
- Контейнер: max-width 1200px, margin auto, padding 0 24px
- Gap между карточками: 24px

### 5. Интерактивность (JS)

- Плавная прокрутка к секциям (smooth scroll)
- Переключатель темы (dark/light) с сохранением в localStorage
- Фильтрация проектов по категориям
- Анимация элементов при скролле (Intersection Observer)
- Прогресс-бары навыков — анимация заполнения при появлении
- Мобильное гамбургер-меню
- Кнопка "Наверх" (появляется после скролла)
- Активный пункт меню при скролле
- Фоновая анимация частиц на Canvas

### 6. Адаптивность

- Desktop: ≥1024px — полная раскладка
- Tablet: 768px–1023px — 2 колонки проектов, сжатые отступы
- Mobile: <768px — 1 колонка, гамбургер-меню, вертикальный стек

### 7. Производительность и SEO

- Семантические HTML5 теги
- Мета-теги (description, viewport, og-теги)
- Ленивая загрузка изображений
- Минимальный CSS/JS без внешних зависимостей (кроме шрифтов)
